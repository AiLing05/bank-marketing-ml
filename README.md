# Bank Marketing Machine Learning Analysis

This repository contains the Python analysis used for the Machine Learning coursework based on the UCI Bank Marketing dataset.

## Dataset

Source: UCI Machine Learning Repository

https://archive.ics.uci.edu/dataset/222/bank+marketing

File used: `bank-full.csv`

## Analysis

The Jupyter notebook includes:

- Data quality investigation
- Missing value and duplicate checks
- Numerical validity checks
- Categorical consistency analysis
- Statistical summary and skewness analysis
- Feature distribution analysis
- IQR outlier detection
- Correlation analysis
- Class imbalance analysis

## Main File

`analysis.ipynb`
